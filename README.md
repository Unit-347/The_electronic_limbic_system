The amplitudes of every time component will become inverted, which means that the peak amplitude of each time component will get inverted, and as a result shifted with the opposite time component, when compared to the original amygdala signal. A peak in amazement will become a peak in trust in the inverted amygdala, if amazement was the loudest emotion normally, inverted trust becomes the loudest. Opposite worlds if you will.

Fear goes from most intense to least intense, in such a setting sadness is the only thing that prevails.
